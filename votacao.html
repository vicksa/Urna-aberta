Sobre esta consulta

Este projeto não é uma urna oficial. Não solicita nome, CPF ou título de eleitor. O banco guarda o código como hash, seu uso e a contagem agregada, sem uma tabela que associe código à escolha. A hospedagem pode manter registros técnicos de acesso. Não oferece as garantias de sigilo de uma eleição oficial.

Um código permite um voto; isso não comprova identidade. Cabe ao organizador entregar apenas um código por participante. Os códigos não vão no endereço do site.
